Habitrack es una aplicacion movil desarrollada para android orientada a la gestion persona de habitos diarios y actividades fisicas al aire libre con gelocalizacion en tiempo real.

La aplicacion cuento con crud para habitos,

Sensor de GPS para el seguimiento de las actividades fisicas por ejemplo caminar cierta distanica, hacia un objetivo, etc

Las rachas son guardadas en un historial dinamico donde se ve si se completaron o no

Teconlogias

Lenguaje: Java

Persistencia SQlite

Geolocalizacion y sensores Google Play Services FusedLocationProviderClient

Ejecuccion asincronica mediante servicios y receptores de emisión para evitar bloqueos

Instalacion y ejecucion

clonar el repositorio git clone https://github.com/LuisCastroST/HabiTrack

Se abre el projecto en Android Studio, sincronizar dependencias de Graddle y ejecutar la app en un dispositivo movil o simulador.
